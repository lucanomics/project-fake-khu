# Project F.A.K.E.

### AI를 잘 쓰는 것에서, AI를 책임 있게 쓰는 것으로.

**경희대학교 세계와시민(Global Citizenship Project) 기반 AI 윤리·디지털 리터러시 프로젝트**

## Project F.A.K.E.는 무엇인가요?

생성형 AI는 과제를 대신 써주고, 이미지를 만들고, 진짜처럼 보이는 가짜 정보까지 생산합니다.
문제는 기술 그 자체보다 **그 결과를 얼마나 비판적으로 확인하고, 책임 있게 사용하는가**에 있습니다.

**Project F.A.K.E.**는 경희대학교 학생들이 AI 시대의 정보를 단순히 소비하는 데서 멈추지 않고,
직접 의심하고, 검증하고, 판단할 수 있도록 돕기 위해 만들어진 디지털 리터러시 프로젝트입니다.

딥페이크, 허위정보, 생성형 AI의 환각(hallucination), 무비판적 복사·붙여넣기처럼
대학생이 실제로 마주칠 수 있는 상황을 어렵고 거창한 윤리 강의 대신
**자가진단, 데이터 시각화, 실천형 툴킷, 참여형 콘텐츠**로 풀어냅니다.

> AI를 쓰지 말자는 프로젝트가 아닙니다.  
> **AI가 만든 결과를 그대로 믿지 않는 사람을 늘리는 프로젝트입니다.**

---

## 왜 만들었나요?

AI 활용 능력이 빠르게 보편화되는 동안, 정보 검증 능력과 윤리적 판단은 자동으로 따라오지 않습니다.

Project F.A.K.E.는 다음 질문에서 출발했습니다.

- AI가 내놓은 답변을 우리는 얼마나 자주 다시 확인하고 있는가?
- 딥페이크나 조작 콘텐츠를 발견했을 때 무엇을 해야 하는가?
- AI 활용의 편리함과 책임 사이에서 어떤 기준을 세울 수 있는가?
- 디지털 리터러시를 시험용 지식이 아니라 실제 행동으로 연결하려면 어떻게 해야 하는가?

그래서 이 프로젝트는 단순한 정보 제공 페이지가 아니라,
사용자가 직접 판단하고 결과를 확인하며 다음 행동까지 이어갈 수 있는 **interactive guide & toolkit**을 지향합니다.

## 주요 기능

### 1. AI 윤리 Self-Check

실제 대학생활에서 마주칠 법한 상황을 바탕으로 자신의 AI 활용 습관을 점검할 수 있습니다.

예를 들어:

- 과제에서 AI 답변을 어떻게 검증하는지
- 친구의 딥페이크 이미지가 공유되었을 때 어떻게 행동하는지
- AI가 생성한 정보와 콘텐츠를 얼마나 비판적으로 소비하는지

각 선택을 통해 단순한 정답 암기가 아니라 **자신의 디지털 행동을 돌아보는 경험**을 제공합니다.

### 2. 데이터 기반 문제 인식

AI 활용, 책임 인식, 딥페이크, 위험 노출 등과 관련된 데이터를
**Chart.js 기반 시각화**로 보여줍니다.

숫자를 길게 늘어놓는 대신, 한눈에 현재 문제를 이해할 수 있도록
Bento-style dashboard 형태로 구성했습니다.

### 3. 실천형 AI 리터러시 Toolkit

알아두면 좋다는 말로 끝내지 않고 실제 행동으로 이어질 수 있도록
여러 실천 자료와 외부 문서를 연결합니다.

- 정보 검증과 교차 확인
- AI 결과물의 책임 있는 활용
- 딥페이크 및 조작 콘텐츠 대응
- 안전한 디지털 시민으로서의 행동 가이드

### 4. 참여와 Pledge

AI 윤리는 혼자만 조심한다고 끝나는 문제가 아닙니다.
Project F.A.K.E.는 사용자가 책임 있는 AI 사용 원칙에 참여하고,
개인의 판단을 공동체의 문화로 확장할 수 있도록 참여형 섹션을 제공합니다.

### 5. 12개 언어 지원

더 많은 학생이 언어 장벽 없이 접근할 수 있도록 다국어 인터페이스를 제공합니다.

`한국어` · `English` · `中文` · `日本語` · `Español` · `Français` · `Русский` · `Italiano` · `हिन्दी` · `Bahasa Indonesia` · `Монгол` · `Afrikaans`

## 디자인 방향

Project F.A.K.E.는 AI 윤리를 다룬다고 해서 페이지까지 교과서처럼 만들 필요는 없다고 판단했습니다.

그래서 다음 원칙을 사용합니다.

- **Friendly, not childish**: 어렵지 않지만 가볍게만 보이지 않는 디자인
- **Visual first**: 긴 설명보다 카드, 아이콘, 차트 중심의 정보 구조
- **Action oriented**: 읽고 끝나는 콘텐츠보다 진단과 실천으로 연결
- **Mobile responsive**: 모바일에서도 핵심 콘텐츠를 자연스럽게 탐색
- **Multilingual by design**: 번역을 부가기능이 아니라 기본 UX로 고려

## Local Development

별도의 빌드 과정은 필요하지 않습니다.

### 1. Clone

```bash
git clone https://github.com/lucanomics/project-fake-khu.git
cd project-fake-khu
```

### 2. Run a local server

Python이 설치되어 있다면:

```bash
python -m http.server 8000
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000
```

F.A.K.E ID는:

```text
http://localhost:8000/id-card.html
```

> 단순히 HTML 파일을 직접 열 수도 있지만, 브라우저 보안 정책과 일부 웹 기능 때문에 로컬 HTTP 서버 사용을 권장합니다.

## Project Principles

Project F.A.K.E.가 전달하려는 핵심은 복잡하지 않습니다.

1. **Verify before you trust.**  
   AI가 말했기 때문에 사실인 것은 아닙니다.

2. **Think before you share.**  
   조작된 콘텐츠의 피해는 공유 버튼 하나로 커질 수 있습니다.

3. **Use AI, but keep responsibility human.**  
   도구를 사용한 책임까지 도구에게 넘길 수는 없습니다.

4. **Digital literacy is a civic skill.**  
   정보를 판별하는 능력은 이제 개인의 공부 습관을 넘어 시민 역량의 일부입니다.
